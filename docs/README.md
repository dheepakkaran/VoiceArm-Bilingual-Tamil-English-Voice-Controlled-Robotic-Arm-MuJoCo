# docs/

Media the README embeds: the animated demo GIF and the milestone screenshots.

`media/demo.gif` is generated by `scripts/make_gif.py`. The `.mp4` files are the
full-resolution renders the milestone scripts produce; GitHub shows a relative
`.mp4` as a link rather than a player, which is why the README uses the GIF.

There is no GitHub Pages site. There was a hand-written `index.html` here, but
once the GIF animated inline the page's only remaining job was playing the
videos at full resolution -- and it duplicated nine measured numbers from the
README, which is a drift risk with nothing to show for it.
